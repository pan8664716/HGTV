# 红果TV · 手机版交互原型

单文件：`index.html`。双击用浏览器打开。无外链、无图片素材（封面 / 二维码 / 图标全部 CSS 与内联 SVG）。

## 这一版和上一版的关系

- **材质与外壳沿用上一版手机原型**：新拟态（凸起 / 按入 / 浮起）、392×856 Android 与 390×844 iOS 两套外壳、底部五栏、应用栏、卡片圆角 20、海报 14。
- **界面与逻辑按代码重做**：页面结构、信息层级、每个入口的去向都以 `MainActivity*` / `ListPage` / `core` 为准。
- **横屏电视版面已全部撤掉**：不再有 1280×720 画布、顶部五个圆形入口、页头收展、六列栅格、10×2 选集。

## 页面与源码对照

| 原型 | 依据 |
| --- | --- |
| 首页七栏 | `core/HomeLayout.kt`：历史记录 / 我的收藏 / 稍后观看 / 热播漫剧 / 热播真人 / 热播AI / 热播上新 |
| 分类四体裁 + 七行筛选 | `core/CategoryFilters.kt`（全部 / 漫剧 / AI剧 / 真人；主题 / 设定 / 背景 / 推荐 / 受众 / 时间 / 状态） |
| 榜单四榜 | `core/RankBoard.kt`：漫剧 / 真人 / AI剧 画名次，上新不画名次 |
| 搜索 | `MainActivitySearch.kt`：输入框 + 搜索，空输入铺热搜与历史，点词即搜 |
| 详情 | `MainActivityDetail.kt`：7:10 海报、四枚等宽按钮、简介两行 / 展开、相关剧集 |
| 选集 | `player/EpisodeGrid.kt`：一页 20 集、到边缘翻页；竖屏重排为 5 列 4 行 |
| 播放 | `MainActivityPlayer.kt`：16:9 画面、顶部剧名与时钟、底部播放键 / 进度 / 状态行 / 下拉箭头 |
| 播放设置 | `MainActivityPlaybackMenu.kt`：清晰度 / 倍速 / 画面 / 解码 / 弹幕 / 速度 / 字号 / 透明度 / 定时 |
| 我的 | `MainActivityProfile.kt` + `MainActivityAccountPanel.kt`：未登录整页登录卡；已登录身份行 + 四栏 |
| 设置 | `MainActivitySettings.kt`：播放偏好 / 片单与设备 / 弹幕 / 按键设置 / 主题外观 |
| 主题 | `tv/TvTheme.kt`：20 套（10 深 + 10 浅），只换色值 |
| 卡片菜单 | `MainActivityHome.quickActions`：继续观看 / 收藏 / 稍后观看 / 详情 / 删除记录 / 不在热播榜中显示 |
| 备份 | `TvTools.libraryTransfer`：局域网二维码 + 合并恢复 |
| 清空缓存 | `MainActivityReset.kt`：不可撤销，危险色 |
| 播完推荐 | `showSeriesFinished`：底部「换一部接着看」 |

## 修顺的地方

| 问题 | 处理 |
| --- | --- |
| 首页剧架和底部栏层级打架 | 剧架只做横向滚动，纵向滚动交给页面主体；底部栏固定 76，内容底部留出等量空白 |
| 分类筛选无处可点 | 改成「入口按钮 + 底部弹层」，选完立刻回填摘要 |
| 详情四按钮换行 / 被挤 | 四枚等分 flex，字号降到 12，高度 44 |
| 选集在竖屏里一行 10 格太窄 | 改 5 列 4 行，一页仍是 20 集 |
| 播放器用横屏版面 | 改 16:9 画面居中，控制层贴底，浮层从底部升起 |
| 二级页还挂着底部栏 | 详情 / 播放 / 设置 / 集合页一律不留底部栏，左上圆形返回 |

## 交互

- 流程图：6 阶段 24 屏，点缩略图直接进演示。
- 演示：Android / iOS 切换、20 套主题、7 种弹层、卡片 → 详情 → 播放 → 选集 → 切集全链路可点。
- `Esc`：先关弹层，再回上一页。
