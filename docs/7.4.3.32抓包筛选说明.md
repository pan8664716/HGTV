# 7.4.3.32 抓包筛选说明

## 结论

原始 HAR `7.4.3.32抓包数据.har` 共 983 条，SHA-256 `a13c14f96047577ad4919acc1ae9e8bc2ee7f559e7e5085e8d1e4cc1ad7fe468`。
筛出 HGTV 当前及未来可能使用的 API 样本 258 条，剔除 725 条。
筛出文件 `7.4.3.32抓包数据_HGTV.har`（23.1 MiB），逐条索引 `7.4.3.32抓包数据_HGTV_index.csv`，逐参数表 `7.4.3.32抓包数据_HGTV_params.csv`，端点参数清单 `7.4.3.32抓包数据_HGTV_参数清单.md`，校验清单 `7.4.3.32抓包数据_HGTV_manifest.json`。

**这是无损筛选**：只删除无关条目。保留条目的 URL、完整 query 参数、headers、Cookie、postData、响应体、请求耗时及 Reqable 私有字段均逐字段保持原值；不做脱敏、截断、去重或压缩。原始 HAR 未改动。
参数表只展开参数名与字段值；完整原始请求体/响应体仍在无损 HAR 中。用 Python 读取大字段 CSV 时，先设置 `csv.field_size_limit(sys.maxsize)`。
生成后逐条与原始条目做结构相等校验：通过。

## 本次 HAR 的缺口

筛选规则已经预留以下 HGTV 已知链路，但本次抓包未出现对应请求，不能从本份数据补齐参数：

- 设备注册：`/service/2/device_register/`
- 手机号发码：`/passport/mobile/send_code/v1/`
- 验证码登录：`/passport/mobile/sms_login/`
- 扫码登录：`/passport/web/get_qrcode/`
- 会话心跳：`/passport/token/beat/v2/`
- 分类/榜单：`/reading/distribution/category/landpage/v/`
- App 搜索：`/reading/bookapi/search/tab/v`
- 搜索联想词：`/reading/bookapi/search/suggest/v`

本次抓包有 `/novel/player/video_model/v1/` 单集播放地址样本；不要把它与缺失的旧备用批量链路混为一谈。

## 以后怎么查参数

1. 打开 `7.4.3.32抓包数据_HGTV_参数清单.md`，按分类和端点查看 Query 参数名、Body 字段、请求头与响应顶层字段。
2. 打开 `7.4.3.32抓包数据_HGTV_params.csv`，按 `sourceIndex` / `scope` / `name` 筛选，取完整参数值；表内不做截断。
3. 打开 `7.4.3.32抓包数据_HGTV.har`，按 `sourceIndex` 对照 `7.4.3.32抓包数据_HGTV_index.csv` 找到原始条目，复放时直接用该条目的完整请求。

python3 tools/filter_hgtv_har.py
